# 六人掼蛋游戏规则说明书 V1.0

> 规则版本：`six_player_guandan_v1`

## 1. 基本设置

| 项目 | 规则 |
|------|------|
| 玩家人数 | 6 人 |
| 队伍 | 2 队，每队 3 人 |
| 牌副数 | 3 副牌，共 162 张 |
| 每人手牌 | 27 张 |
| 底牌 | 无 |
| 起始级数 | 2（即打 2） |

## 2. 座位与组队

```text
           P3 (B)
      P2 (A)    P4 (A)
      P1 (B)    P5 (B)
           P0 (A)
```

- A 队：P0、P2、P4
- B 队：P1、P3、P5
- 座位顺序：A B A B A B（逆时针）

## 3. 级牌与逢人配

- **级牌**：当前级别的牌。例如打 2 时，所有 2 为级牌。
- **逢人配**：当前级数的**红桃**花色，可代替任意牌（除大小王外）。
- 逢人配单独打出时，按级牌点数计算。

## 4. 牌型

| 牌型 | 说明 |
|------|------|
| 单牌 | 1 张 |
| 对子 | 2 张相同点数 |
| 三张 | 3 张相同点数 |
| 三带二 | 3 张相同 + 2 张相同（对子） |
| 顺子 | 5 张及以上连续点数（不含 2 和王） |
| 三连对 | 3 对及以上连续对子 |
| 钢板 | 2 个及以上连续三张 |
| 同花顺 | 5 张及以上同花色连续 |
| 炸弹 | 4 张及以上相同点数 |
| 王炸 | 2 张小王 + 2 张大王（至少各 2 张） |

## 5. 牌型大小

1. **王炸** > 所有炸弹 > 其他牌型
2. **炸弹**：张数多者大；张数相同则点数大
3. **同牌型**：点数大者胜（顺子、三连对、钢板比较最大牌点数）
4. **非同牌型**：只有炸弹/王炸可以压非炸弹牌型
5. **级牌**在比较时按正常点数，红桃级牌作逢人配时不单独计点

## 6. 出牌规则

1. 首家可出任意合法牌型
2. 后续玩家必须出**同牌型且更大**的牌，或 **Pass（过）**
3. 一轮中所有其他玩家 Pass 后，最后出牌者获得新一轮首出权
4. 已出完牌的玩家跳过，不再参与出牌

## 7. 游戏结束

- 玩家出完所有手牌后获得当前名次（头游、二游……）
- 当一方 3 名队员**全部出完**时，本局结束
- 若仅剩未出完者均属于同一队，也视为结束

## 8. 结算（MVP 简化版）

| 结果 | 说明 |
|------|------|
| 双下 | 一方获得头游+二游 → 升 3 级 |
| 单下 | 一方头游且队友三游 → 升 2 级 |
| 平局 | 双方各一游 → 升 1 级 |

MVP 阶段暂不实现进贡、还贡、抗贡。

## 9. 超时

- 轮到出牌后 **30 秒**未操作，服务器自动 Pass
- 客户端倒计时仅作显示，以服务器为准

## 10. 下一局

- 本局头游所在队伍下一局先出牌
- 级数按结算结果升级
